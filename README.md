### Состав проекта:
- `index.html` — кинематографическая интерактивная презентация с видео-фоном, голосовыми ответами агента ИВАНА и финансовым калькулятором.
- `vote-tpp.html` — адаптивное мобильное веб-приложение для аудитории (голосование по QR-коду со смартфонов).
- `РЕЖИССЕРСКИЙ_СЦЕНАРИЙ_ВЫСТУПЛЕНИЯ_ТПП_ИВАН.docx` — подробный диалоговый сценарий на 60 минут.
- `Презентация_Сильные_Стороны_БРЕНДБУК_ИНТЕРАКТИВ_16x9.pptx` — резервный вариант слайдов в PowerPoint.

*Проект разработан командой «Сильные стороны»: Алексей Бармин, Дмитрий Кравченко, Павел Ерагер.*
